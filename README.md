# Worldbook Tags Extension for SillyTavern

A tag management system for organizing and filtering your worldbooks in SillyTavern.

## Features

- 🏷️ **Tag Management**: Add custom tags to worldbooks
- 🔍 **Tag Filtering**: Filter worldbooks by tags (supports multiple tags)
- 🎨 **Theme Adaptive**: Automatically matches your SillyTavern theme
- 📱 **Mobile Friendly**: Works on mobile devices

## Usage

**Manage Tags**: Click the tags button (🏷️) to add/remove tags for each worldbook

**Filter by Tags**: Click the filter button (🔍) to select tags and filter your worldbook list

## Data Storage

Tags are stored in browser localStorage and don't modify your original worldbook files.
